
# Day 2: HTML Foundations — Personal Introduction

A personal portfolio website built using HTML5 and CSS3 as part of my Web Development learning journey.

The project introduces my background, education, technical skills, projects, goals, and contact links through a modern, responsive portfolio layout.

## 🎯 Learning Objectives

Through this project, I practised:

- Understanding the basic structure of an HTML document.
- Using semantic HTML elements such as `header`, `nav`, `main`, `section`, `article`, and `footer`.
- Creating headings, paragraphs, lists, and hyperlinks.
- Organising content using `class`, `id`, and meaningful HTML attributes.
- Connecting an external CSS stylesheet to an HTML document.
- Styling webpages using CSS selectors, variables, Flexbox, and Grid.
- Creating hover effects, transitions, and simple animations.
- Making webpages responsive using CSS media queries.
- Managing project files and uploading code to GitHub using Git.

## ✨ Features

- **Navigation Bar:** Links to the main sections of the portfolio.
- **Hero Section:** A short introduction with call-to-action buttons.
- **About Me:** Personal introduction and learning interests.
- **Education:** Academic background and degree information.
- **Technical Skills:** Overview of technologies currently being learned.
- **Featured Projects:** Examples of beginner programming and web projects.
- **Goals:** Future learning and career objectives.
- **Contact Section:** Links for email, GitHub, and LinkedIn.
- **Responsive Layout:** Adapts to desktop, tablet, and mobile screens.
- **Interactive Styling:** Hover effects, gradient colours, and animations.

## 🚀 How to Run the Project

No installation or build tools are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/svenchaudhary/bcs2026470-shantanu-webdev-day02-personal-intro-page.git
   ```

2. Open the project folder:

   ```bash
   cd bcs2026470-shantanu-webdev-day02-personal-intro-page
   ```

3. Open `index.html` in a web browser.

4. Alternatively, open the folder in VS Code and use the Live Server extension.

**Note:** The Google Fonts import in the CSS file requires an internet connection. The rest of the webpage can run locally.

## 📚 HTML Concepts Practised

| Concept | Purpose |
|---|---|
| `<!DOCTYPE html>` | Declares an HTML5 document. |
| `<head>` | Contains metadata and linked resources. |
| `<title>` | Sets the browser tab title. |
| `<header>` | Defines introductory page content. |
| `<nav>` | Groups navigation links. |
| `<main>` | Contains the primary page content. |
| `<section>` | Groups related content. |
| `<article>` | Represents a self-contained content item. |
| `<footer>` | Contains closing information. |
| `id` and `class` | Identify elements and group them for styling. |
| `data-*` attributes | Store custom data on HTML elements. |
| `<a>` | Creates hyperlinks. |
